[REPORT 1]Bulk Customer Account ID Disclosure
BugBase #72629840

Endpoint: GET /v1/api/features/sdk-production-G5hzhqMWonPN3S1q

An unauthenticated, publicly-accessible feature flag endpoint leaks 127 unique real Groww customer account IDs in sequential ACC###### format. No authentication required; ID enumeration trivial via HTTP client.

Critical signal
  • 127 live customer IDs extracted from single request
  • No authentication barrier; public endpoint
  • Sequential ID pattern enables brute-force account enumeration
  • Customer financial account exposure (Groww = investment platform)
[REPORT 2]Unauthenticated User Enumeration
BugBase #63683036

Endpoint: POST /v1/api/user/v2/login/check_email

Pre-login email validation returns structurally different JSON responses depending on whether an email is registered, and whether the user has a password credential set. Three independent oracles enable rapid account enumeration and credential-method disclosure.

Elevated signal
  • Three independent response oracles: already_exists, password_exists, structural keys
  • No rate limiting observed
  • Enables targeted phishing and credential-stuffing prioritization
  • Fintech target = high-value account enumeration
[REPORT 3]Internal Infrastructure IP Disclosure
BugBase #50213014

Records: jenkins.groww.in, spinnaker.groww.in, alertmanager.groww.in, portal.groww.in, portal.growwmf.in

In-scope wildcard subdomains resolve via public DNS to private RFC1918 addresses. Hostnames disclose internal CI/CD, monitoring, and admin tooling; allows network reconnaissance and SSRF/post-foothold chaining.

Moderate signal
  • 5 internal IPs disclosed: 10.82.10.9, 10.80.50.105, 10.69.0.90, 10.154.80.81, 10.140.8.54
  • Not remotely routable, but maps internal topology
  • Descriptive hostnames leak internal services (Jenkins, Spinnaker, Alertmanager)
  • Useful for post-compromise lateral movement targeting
