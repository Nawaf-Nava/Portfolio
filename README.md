## About

Personal portfolio for **Nawaf**, a student interested in software development and AI projects. The portfolio interface is retained while personal content is being replaced with verified information.

## Current project areas

- **NAVA AI** — an AI model and assistant project.
- **ZANAX** — a web-based software project.
- **Web applications and tools** — ongoing development and experimentation.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Three.js / React Three Fiber

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

```bash
npm run build
npm run start
npm run lint
```
